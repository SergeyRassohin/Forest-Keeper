# Итоги обсуждений Forest Keeper — сентябрь 2026

Ключевые договорённости:

- FK — vendor-neutral интеллектуальный слой над существующими системами.
- MVP 0.1 read-only по отношению к 1С и другим исходным системам.
- Первый реалистичный сценарий: маленькая компания, 1С + Excel, возможно простая CRM.
- Каноническое представление не является золотым эталоном.
- FK имеет преднастроенную модель мастер-данных, которую заказчик может настраивать.
- Authoritative Source может назначаться вплоть до уровня атрибута.
- NOT_DEFINED — допустимое состояние.
- При неизвестной истине FK показывает конфликт, а не выдумывает правильное значение.
- Решения людей сохраняются в Decision Registry.
- Recommendation Engine использует похожие подтверждённые решения.
- AI не является корпоративной памятью.
- Главный экран — состояние информационной среды, а не таск-трекер.
- GitHub становится единым инженерным источником истины.
- ChatGPT используется для обсуждения и проектирования.
- Codex используется для разработки в репозитории.
- Значимые решения должны фиксироваться в GitHub.
- Нужны security testing, SAST/SCA/DAST, fuzzing, AI red teaming и независимый pentest.
- Проектный сайт / Project Portal должен работать поверх Git-backed контента и не становиться вторым источником истины.
