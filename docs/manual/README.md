# Forest Keeper — руководство владельца ПК

**Актуально: 30.10.2026.** Это единая точка входа для самостоятельной локальной проверки **принятой ветки `main` (Stage 0–8)**, а не всей ещё не завершённой промышленной версии.

Читайте по порядку:

1. [Установка и первоначальная настройка](installation.md).
2. [Как пользоваться интерфейсом](user-guide.md).
3. [Пошаговый сценарий с чеклистом и ожидаемыми результатами](walkthrough-checklist.md).
4. [Ошибки, диагностика и безопасное восстановление](troubleshooting.md).

**Что есть в `main`:** импорт CSV/XLSX/XML, неизменённые исходные данные и provenance, нормализация, сопоставление, конфликты, ручное принятие решения и Decision Registry, ограниченный Similar Decision Retrieval, детерминированный Recommendation Engine с явными ограничениями и светлая/тёмная тема.

**Чего нет в `main`:** работающего локального Qwen runtime. Stage 9 существует **только в отдельном draft PR #33** и **BLOCKED** по качеству/нагрузке. В обычной production-конфигурации embedding retrieval недоступен; positive recommendation из synthetic test provider не является production доказательством. Для первого личного запуска **не загружайте модели Qwen** и не включайте синтетический provider. Сначала проверьте данные, конфликт и человеческое решение.

Эта установка предназначена для локального теста на несекретных учебных данных. Это не сертифицированная установка в корпоративной сети. Никогда не загружайте сюда рабочие данные предприятия без отдельного разрешения и оценки безопасности.

Исторические документы и полные инженерные инструкции: [external-review-quickstart](../deployment/external-review-quickstart.md), [review readiness](../deployment/review-readiness.md), [Stage 9 PR #33](https://github.com/SergeyRassohin/Forest-Keeper/pull/33). Исторические пометки в старых отчётах относятся к дате их создания; для личного запуска ориентируйтесь на этот комплект и фактический SHA `main`.
