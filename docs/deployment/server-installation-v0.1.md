# Forest Keeper: развёртывание для внешней проверки

Статус на 21 октября 2026: техническая проверка принятых этапов 0–4. Полный продуктовый сценарий ещё не готов; [блокеры](review-readiness.md) обязательны к учёту. Корпоративный установщик — будущая функция.

## Локальная машина проверяющего

Используйте [пошаговый Quick Start](external-review-quickstart.md). В нём приведены проверенные команды установки зависимостей, запуска, первого администратора, работы с данными и перезапуска. Это основной исполняемый сценарий; здесь описаны границы серверного развёртывания.

Development Compose слушает только loopback: HTTPS 8443, backend 8000, PostgreSQL 5432, Redis 6379. Браузер обращается к HTTPS gateway; прямой доступ к внутренним компонентам не нужен. Для удалённого сервера используйте SSH-туннель:

```bash
ssh -L 8443:127.0.0.1:8443 user@server
```

Откройте https://localhost:8443 локально; терминал с туннелем должен оставаться открытым. Если этот порт занят на вашей машине, сначала освободите его. Изменение hostname/Origin требует согласованной настройки FK_ALLOWED_ORIGINS и TLS, см. [auth](../development/authentication.md).

## Тестовый сервер с отдельным HTTPS hostname

Для администратора, настраивающего отдельный стенд, есть [production-профиль](production-profile.md) и `compose.production.yaml`. Он требует собственного конфигурационного файла, секретов и сертификата. Не смешивайте development и production Compose через несколько `-f`. Это технический профиль контейнеров, не готовый installer и не автоматическая офлайн-поставка.

На свежей установке после migrations обязательно создаётся первый ADMIN через `app.auth.bootstrap`. Затем через Web Client создаются пользователи с необходимыми ролями; ADMIN не получает право бизнес-решений автоматически. [Команда и ограничения](../development/authentication.md#первый-администратор).

Данные PostgreSQL и оригиналы импортов сохраняются в named volumes. Обычный restart/down без `-v` их сохраняет; удаление volumes — разрушительная операция. Перед обновлением или сменой профиля сделайте резервную копию; наличие volume не заменяет backup.

## Данные и AI

Проверяющий начинает с [открытого примера](../../tests/data/external-review/README.md), затем пробует собственный CSV/XLSX/XML. Произвольная структура файла требует явно подходящего normalization mapping; автоматического понимания любой выгрузки нет. Поддерживаемые ограничения: [импорт](../development/import.md), [нормализация](../development/normalization.md).

Точные модели и загрузка: [Qwen artifacts](../ai/model-downloads.md), [архитектурный baseline](../ai/local-model-v0.1.md), [manifest](../../models/model-manifest.yaml). Для импорта и нормализации Qwen не требуется. Проверка/получение файлов реализована отдельно от AI runtime. Запуск LLM/embedding services и inference smoke ещё не поддерживаются текущим Compose, не выдавайте загрузку файлов за готовность AI.

## Граница внешней приёмки

Цель к **24 октября 2026**: «свой файл → анализ → решение человека → сохранённая память → похожий случай → рекомендация». Matching принят и доступен в main. Отсутствие Conflict/Decision/retrieval/inference остаётся блокером этой цели. Запись о будущем сценарии не является инструкцией нажать несуществующую кнопку. [Матрица готовности и необходимые доказательства](review-readiness.md).

Для этой проверки не требуются production installer, SSO, NX/Teamcenter/SAP connectors, полноценный Forest Codex runtime или HA/DR. Desktop Client исключён из направления продукта решением от 21 октября, а не отложен.
