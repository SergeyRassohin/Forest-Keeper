# Forest Keeper — Server Installation Guide v0.1

1. **Получить дистрибутив Forest Keeper Server.**  
   Пакет должен включать всё необходимое для offline-установки в закрытой сети.

2. **Подготовить сервер.**  
   Выделить физический или виртуальный сервер, соответствующий требованиям по ОС, CPU, RAM, дискам и сети.

3. **Запустить установщик.**  
   Войти с административными правами и запустить `Forest Keeper Server Setup`.

4. **Проверить готовность сервера.**  
   Установщик проверяет ОС, ресурсы, свободное место, сеть и системные компоненты.

5. **Выбрать каталоги.**  
   Указать каталог установки и размещение постоянных данных: DB, raw files, audit, config, backups.

6. **Настроить сетевые параметры.**  
   Указать имя сервера, адрес, порты и допустимые интерфейсы.

7. **Настроить TLS.**  
   Установить корпоративный TLS-сертификат или использовать предусмотренный механизм bootstrap.

8. **Настроить административный доступ.**  
   Подключить корпоративную identity-систему либо создать initial admin account.

9. **Подтвердить установку.**  
   Проверить параметры и начать deployment.

10. **Развернуть компоненты.**  
    Installer автоматически разворачивает container runtime и компоненты FK.

11. **Настроить внутреннюю инфраструктуру.**  
    Installer создаёт сети, БД, каталоги и конфигурацию.

12. **Запустить Forest Keeper.**  
    Все обязательные компоненты запускаются.

13. **Выполнить health check.**  
    Проверяется DB, API, backend, storage и остальные компоненты.

14. **Активировать лицензию.**  
    Online либо импортировать подписанный `forestkeeper.license`.

15. **Получить подтверждение готовности.**  
    Показать версию, адрес, статус компонентов и лицензионный статус.

16. **Выполнить первоначальную настройку.**  
    Пользователи, роли, источники, master-data template, mappings и правила клиента.

17. **Установить Desktop Client при выбранной модели.**  
    Централизованно установить клиент только на разрешённые рабочие станции и настроить защищённое подключение.
