# Forest Keeper — Data Model

Для разработки MVP использовать `data-model-v0.2.md` как каноническую логическую модель данных.

`Forest_Keeper_Data_Model_v0.1.xlsx` сохранён как исторический черновик и визуальная табличная версия ранней модели. Он содержит старые коды некоторых состояний и ролей и **не должен использоваться Codex как источник enum/status для реализации**.

Канонические состояния объектов задаются также `../development/object-lifecycles-v0.1.md`, а права — `../security/access-control-matrix-v0.1.xlsx`.
