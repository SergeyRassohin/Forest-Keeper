## Наблюдения и ограничения

Блокирующих находок нет. Неблокирующее предупреждение: Starlette сообщает deprecation использования httpx в TestClient; текущие тесты проходят. pip-audit предупредил о недоступном стандартном pip cache и продолжил успешно без него.

При отказе PostgreSQL защищённый API возвращает generic 500; health возвращает 503. Доступ не разрешается, traceback клиенту не выдаётся. Единый структурированный ответ на неожиданные DB errors этим этапом не доказан и не объявляется реализованным.

Первые попытки дополнительного стенда выявили ошибки самого probe: совпадение тестового login, неполное окружение Alembic, ожидание готовности временного PostgreSQL и смена автоматически назначенного Docker host port после restart. Эти прогоны завершались ошибкой, fixtures очищались; финальные probes исправлены и завершились exit0. Первоначальный Redis 503 после restart оказался обращением по прежнему динамическому порту, дефект продукта не подтверждён.

Сохранены [API probe](auth-rbac-2026-10-15/probe-api.py), [outage probe](auth-rbac-2026-10-15/probe-outages.py), [log probe](auth-rbac-2026-10-15/probe-logs.py), [web probe](auth-rbac-2026-10-15/probe-web.cjs) и sanitized результаты рядом. Это вспомогательные scripts конкретного ревью, не постоянный набор CI. Запускать только на disposable development environment, Python probes из `backend` с экспортированной `.env`, через `uv run --frozen python <path>`; logs probe требует `FK_TEST_INTEGRATION=1`. Outage probe сам создаёт и удаляет собственные containers. Web probe привязан к путям этой облачной среды и пишет evidence в `/tmp`.

Штатный Gitleaks проверяет tracked files. Новая папка reports дополнительно просканирована тем же закреплённым Gitleaks image через `dir --redact`: 35.29 KB, no leaks, exit0. Значения credentials сюда не копировались. Перед commit следует включить новые файлы в обычный secrets gate.

Итог независимого статического ревью и выполненных runtime-проверок: оснований возвращать реализацию на исправление не найдено. Для буквального выполнения каждого варианта исходного сценария остаются указанные расширения покрытия (73-секундное ожидание, отдельные browser edge cases и DB snapshots). Решение о merge/приёмке не выполнялось автоматически. MFA, pentest и остальные ограничения пилота из authentication.md сохраняются.
